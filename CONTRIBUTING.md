# Contributing

## Code organization

- Model classes belong in app.model.
- Pathfinding algorithms belong in app.sequential.
- Parallel execution belongs in app.parallel.
- Experiments belong in app.experiment.

## Naming conventions

- Classes: PascalCase
- Methods and variables: camelCase

## Testing

- Add unit tests for new functionality.
- Run `mvn test` before submitting changes.

## Git

- Use descriptive commit messages.
- Do not commit generated build files.
