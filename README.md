# Parallel Pathfinding on Grid

A Java project that implements sequential and parallel
pathfinding algorithms on a 2D grid.

## Features

- BFS pathfinding
- Dijkstra pathfinding
- Multiple independent path requests
- Parallel execution using ExecutorService
- Performance experiments

## Requirements

- Java 17+
- Maven

## Build

mvn compile

## Run

mvn exec:java

## Test

mvn test
